# Project C06

In this project we learn to use arguments. There were 4 exercises, from 00 to 03. I did all.

#### Exercise 00 : ft_print_program_name
Files to turn in : `ft_print_program_name.c`. Allowed functions : `write`. <br>
We’re dealing with a program here, you should therefore have a function main in
your .c file. <br>
Create a program that displays its own name followed by a new line. <br>
Example: 
```s
$>./a.out | cat -e
./a.out$
$>
```
[ex00/ft_print_program_name.c](ex00/ft_print_program_name.c)

#### Exercise 01 : ft_print_params
Files to turn in : `ft_print_params.c`. Allowed functions : `write`. <br>
We’re dealing with a program here, you should therefore have a function main in
your .c file.<br>
Create a program that displays its given arguments. One per line, in the `same order` as in the command line.
It should display all arguments, except for argv[0]. <br>
Example: 
```s
$>./a.out test1 test2 test3 | cat -e
test1$
test2$
test3$
$>
```
[ex01/ft_print_params.c](ex01/ft_print_params.c)

#### Exercise 02 : ft_rev_params
Files to turn in : `ft_rev_params.c`. Allowed functions : `write`. <br>
We’re dealing with a program here, you should therefore have a function main in
your .c file.<br>
Create a program that displays its given arguments. One per line, in the `reverse order` of the command line.
It should display all arguments, except for argv[0]. <br>
[ex02/ft_rev_params.c](ex02/ft_rev_params.c)

#### Exercise 03 : ft_sort_params
Files to turn in : `ft_sort_params.c`. Allowed functions : `write`. <br>
We’re dealing with a program here, you should therefore have a function main in
your .c file.<br>
Create a program that displays its given arguments `sorted by ascii` order. It should display all arguments,
except for argv[0]. One argument per line. <br>
[ex03/ft_sort_params.c](ex03/ft_sort_params.c)
