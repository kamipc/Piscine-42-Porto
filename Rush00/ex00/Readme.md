# Project Rush00
Files to turn in : `main.c`, `ft_putchar.c`, `rush0X.c`. Allowed functions : `write`. <br>
You must create the function rush taking two variables of type int as
arguments, named respectively `x` and `y`. <br>
Your function rush should display (on-screen) a rectangle of `x` characters for `width`,
and `y` characters for `length`.<br>
Your main will be modified during defense, to check if you’ve handled everything
you’re supposed to.<br>

`I made a mistake in the name of the function which was the culprit of my low grade.`
